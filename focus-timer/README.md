# focus-timer

An AgentSam mini using the gadget starter.

Edit public/index.html, public/style.css, and public/app.js, then refresh the browser.

From this folder, run:

```bash
agentsam mini preview .
```

The preview stays in the foreground on 127.0.0.1, closes after 20 minutes, and stops with Ctrl+C. Use --timeout <seconds> to change the lifetime. Files remain when the preview stops. Only public/ is served.

No install step is needed. To share later, public/ is a plain static site; publishing is separate.
