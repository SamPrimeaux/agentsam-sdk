# Open Graph game preview

Target a 1200×630 preview by default, unless the destination documents a
different size. Compose it from approved game art, a verified engine frame, or
an available provider-neutral image-generation capability. Preserve the
project's established visual quality, motion identity and typography.

Check readability at roughly 320px display width, edge-safe margins, title
contrast, no crop of key subject matter, accurate aspect ratio, correct MIME
type, and a publicly accessible absolute URL. Keep source masters untouched.
