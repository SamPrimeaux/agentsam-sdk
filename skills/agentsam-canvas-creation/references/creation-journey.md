# Canvas entry and creation journey

## Entry/state contract

1. **Opening**: + New opens the authorized host's private Canvas with a quiet,
   spacious stage. Show skeletons only for real loading work; never insert
   decoration as if it were an existing customer document.
2. **Creative direction**: once AgentSam has enough context, show **exactly
   four** equally legible, actionable choice cards. Each has a distinct title
   and brief descriptive difference. Options must be generated or derived
   from the user's actual intent, project, assets and selected medium.
   They are creative propositions, not forced theme IDs or template IDs.
3. **Choice**: selection is an explicit action; store selected direction and
   resulting source/revision provenance. Do not immediately publish, attach
   a merchant site, or require a site picker.
4. **Knowledge acquisition**: read only applicable skills/project docs and
   verify actual capabilities, operations and permissions. Report genuine
   reads, not generic "reviewing files" animations.
5. **Structure first**: create real editable pages/scenes/objects incrementally,
   with hierarchy and consistent IDs, then design/asset/interactions.
6. **Collaborative refinement**: selection, right inspector, agent activity
   and work-in-progress stage stay synchronized. Assistant expands, docks
   or collapses to miniAgentSam without losing context or interrupting runs.
7. **Saved creation**: real persistence, reopen and resume; domain-specific
   handoff is a separate intentional step.

## Four-direction output requirements

- Exactly four choices with stable per-response IDs and distinct titles.
- Vary meaningful creative attributes such as density, tone, interaction,
  typographic expression, motion, visual storytelling or composition.
- Each option is succinct. Avoid color-palette-only variations masquerading
  as four different approaches.
- Preserve user-provided brand materials; no invented claims, stock client
  stories or assumed provider assets.
- Do not repeat identical fixed choices across unrelated surfaces.
- One choice starts execution. "Different direction" can regenerate four
  choices explicitly without creating duplicate documents.

## Genuine progress semantics

The visible stage can only claim an operation after the underlying host reports
it. Events contain target resource, operation identity, affected selection
(if available), previous/current revision and status. Respect cancellation,
manual edits and revision conflict. False percentages and simulated agent
pointer motions are forbidden.

## States to design and verify

Opening, direction-ready, chosen, skills-loading, planning, generating,
inspectable-partial, manual-editing, agent-docked, agent-collapsed, saving,
saved, retryable-failure, unauthorized, missing-asset, canceled, reopened.

A first-time novice and advanced creator should see the same quality of
layout, type rhythm and feedback; specialist controls progressively disclose.
