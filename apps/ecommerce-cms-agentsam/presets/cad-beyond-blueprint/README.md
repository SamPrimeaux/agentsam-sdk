# Beyond the Blueprint CMS component pack

Eight reusable section definitions are registered against the existing Ecommerce CMS catalog and `ThemePortableSections` renderer: Aspiration, Complexity, Uncertainty, Perseverance, Understanding, Capability, Possibility, and Architectural evidence.

The shared renderer is customer-neutral. It contains schemas and generic defaults only. The CAD site's copy, DreamHouse evidence, media references, and anchor values belong to its site-owned `cms_page_sections` records and versioned R2 drafts.

Canonical authorities:
- Reusable catalog: `cms_component_templates`
- Account/site definitions: `cms_definitions`
- Verified renderer bindings: `cms_components`
- Placed instances: `cms_page_sections`
- Nested evidence items: `cms_section_blocks`
- Immutable draft content: R2 bucket `cms`

This pack does not create a second CMS, template catalog, or page authority.
