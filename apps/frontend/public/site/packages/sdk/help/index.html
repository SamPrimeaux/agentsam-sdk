Install

Copy and run in any Node 22+ project:

npm i @inneranimalmedia/agentsam-sdk

Pin exact version

Lock to the version currently published on this site:

npm i @inneranimalmedia/agentsam-sdk@2.6.3

Verify CLI

npx agentsam --version

Inspect a repository

Builds deterministic world-state before any model call.

npx agentsam inspect .
