repo scripts
The public CLI does not currently expose a finished agentsam package command. Use repository verification scripts for this drill.
verification
npm run verify:package
npm run pack:check
npm run test:workspaces
npm run verify:boundaries
npm run verify:release
Good result: SAM reports the exact failing gate and avoids inspecting unrelated subsystems.
