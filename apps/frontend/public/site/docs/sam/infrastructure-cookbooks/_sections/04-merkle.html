Prove Merkle saves work

02
Incremental intelligence testMeasure what can be invalidated versus reused after a bounded change.
runnable now
before
agentsam merkle snapshot . --semantic --out /tmp/sam-before.json

Make one bounded change, then capture the new state:

after
agentsam merkle snapshot . --semantic --out /tmp/sam-after.json
agentsam merkle diff /tmp/sam-before.json /tmp/sam-after.json --json
Good result: SAM can say which subtrees changed, which analyses are invalid, and which previous work can be reused.
