Cookbook 01

Establish a SAM baseline

01
Repository perception before editsCreate a reproducible view of the repo before a large task begins.
runnable now
shell
git status --short
git rev-parse HEAD

agentsam inspect

agentsam merkle snapshot . \
  --semantic \
  --out /tmp/sam-before.json

agentsam index plan --cwd . --json
agentsam index run --cwd . --json

Then query only the surface relevant to the task:

shell
agentsam search "terminal enrollment authentication" \
  --cwd . --top-k 8 --token-budget 4000
Good result: SAM identifies the authority files without requiring a model to crawl the entire repository.
