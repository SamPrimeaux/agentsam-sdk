Three execution modes

Local native

Run the Go process directly for local machine work. AgentSam verifies the built binary by booting it, probing the contract, and requiring clean shutdown.

Cloudflare development

Wrangler runs the Worker edge adapter with the GO_RUNTIME Container binding. This mode is for development, not final production proof.

Production

The normal AgentSam deploy command builds and verifies the native binary and Linux container, deploys with Wrangler, resolves Cloudflare deployment identity, probes the live service, then updates the product registry.

agentsam go --cloudflare agentsam-go-worker
