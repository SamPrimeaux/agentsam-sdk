What counts as shipped

A source tree, Dockerfile, or deployment adapter is not deployment proof. A production receipt is accepted only after the externally reachable service reports healthy and the native health response identifies the intended source commit.

Evidence captured

  • source commit and Go version
  • native binary SHA-256 digest
  • linux/amd64 nonroot container verification
  • Cloudflare deployment ID and Worker version ID
  • deployed URL and timestamped endpoint probes
  • agentsam_products and asset_relationships registration

What comes next

The native runtime graduates next into workspace filesystem execution, file watching, Merkle updates, health/capability state, cancellable jobs, and PTY coordination. Go implements shared AgentSam contracts rather than inventing parallel schemas.
