How to test SAM

A powerful infrastructure primitive is only useful if it removes cognitive work from the operator. Every cookbook asks: did SAM find the smallest correct surface, act deliberately, and prove the result?

human goal
   │
   ▼
SAM perception
   ├─ repository state
   ├─ Merkle delta
   ├─ AST / dependency graph
   ├─ indexed retrieval
   └─ runtime health
   │
   ▼
plan / execute / verify
   │
   ▼
receipt
   ├─ predicted impact
   ├─ actual impact
   ├─ tests
   ├─ evidence
   └─ remaining uncertainty
Rule: do not judge success by whether a command completed. Judge success by whether SAM changed the intended state and preserved unrelated authority.
