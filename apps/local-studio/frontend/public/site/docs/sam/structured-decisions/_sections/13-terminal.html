Pattern: Terminal lane selection

AgentSam has local, remote, and sandbox lanes. The agent should select the lane from task requirements and machine state instead of using a single hardcoded terminal.

lane decision
{
  task: "run repository tests",
  requiresLocalFiles: true,
  untrustedCode: false,
  available: { local: true, remote: true, sandbox: true },
  choice: "local"
}
