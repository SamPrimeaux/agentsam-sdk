Primitive 2: Choice

A choice selects one item from a finite candidate set. Ideal when AgentSam already knows the legal options.

conceptual contract
{
  question: "Which execution lane should run this task?",
  options: ["local", "remote", "sandbox"],
  result: "local",
  confidence: 0.94
}

Good AgentSam uses: tool selection, skill selection, retrieval lane, model class, workflow branch, terminal target, next GOAP action.
