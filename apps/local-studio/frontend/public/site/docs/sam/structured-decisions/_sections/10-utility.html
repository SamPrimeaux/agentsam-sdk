Pattern: Utility scoring

Utility scoring lets multiple possible actions compete using explicit factors. This matches AgentSam’s machine-agent layer.

utility formula
utility =
  (goalProgress * 0.40) +
  (confidence   * 0.20) +
  (reversibility * 0.15) +
  (speed        * 0.15) -
  (risk         * 0.25) -
  (cost         * 0.10);

The exact weights should be policy/configuration, not hidden magic.
