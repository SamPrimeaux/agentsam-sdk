What counts as shipped

A source tree, Dockerfile, or deployment adapter is not deployment proof. A production receipt is accepted only after the externally reachable service reports healthy and both edge and native health identify the intended source identity.

Evidence captured

  • Git or npm package source identity plus deterministic source digest
  • native binary SHA-256 digest
  • linux/amd64 nonroot container verification
  • explicit Cloudflare account identity
  • Cloudflare deployment ID and Worker version ID
  • deployed URL and timestamped endpoint probes
  • local AgentSam registry for self-host deployments
  • agentsam_products / asset_relationships only for guarded IAM official releases

What comes next

The shared native core graduates next into workspace filesystem execution, file watching, Merkle updates, health/capability state, cancellable jobs, and PTY coordination. agentsamd reuses that core as the user-machine runtime; the hosted Go Worker remains a separate service with a different ownership boundary.
