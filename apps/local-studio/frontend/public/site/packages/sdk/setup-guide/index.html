Setup guide

Install the published SDK, verify the CLI, then inspect a repo before any model call. Commands stay synced via npm run site:sync.

  1. Install 
    npm i @inneranimalmedia/agentsam-sdk
  2. Verify 
    npx agentsam --version
  3. Inspect 
    npx agentsam inspect .
  4. Return to Help or open Learn
