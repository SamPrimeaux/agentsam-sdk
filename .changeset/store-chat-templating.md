Make the Online store chat embed a reusable template. Merchants can drop in an image (launcher icon and chat-header avatar), set icon color and background from theme tokens, edit the chat title, greeting, field labels, send button and confirmation text, and choose a font family and title weight. The chat window is now a conversation layout with a filled or plain header. The theme editor groups these settings, uploads images through the site media library, and previews the packaged widget itself. Existing installs keep working: every new setting defaults to the previous look.
