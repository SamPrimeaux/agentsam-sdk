# @inneranimalmedia/theme-forge

**Forge** is an AgentSam prebuild for trades / local services.

Built to get the phone ringing.

A mobile-first local-services prebuild with estimate capture, service-area confidence, project proof, reviews, and practical trust signals that stay sharp on the smallest screen.

Demo identity: **Forge Works**. The demo content is fictional and exists to show the layout, interaction, and content system without carrying customer branding forward.

The complete built platform ships in `site/`; installation does not depend on the AgentSam gallery or a sync step.
