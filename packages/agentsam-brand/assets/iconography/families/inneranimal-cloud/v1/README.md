# InnerAnimal Cloud System Icons v1

Original source family extracted from `ia-cloud-exports(2).zip`:

- `custom-cloud-download-si`
- `custom-cloud-code-si`

The original source SVG, favicon SVG and monochrome black/white SVGs are preserved in `source/`. The original PNG/ICO exports (favicon, iOS, Android adaptive, Play Store, PWA and Shopify) are retained byte-for-byte in the Library folder `/PrimeTech/Brand References/Cloud Icon Exports`.

`family.manifest.json` maps the original SVGs into the shared AgentSam Brand icon-family contract. The build adds a standardized 16/24/32/48/64/128/256 favicon ladder, multi-frame ICO, Apple touch icon, PWA icons and app/WebP sizes.
