# Brand icon families

This directory contains original, editable icon-family sources consumed by the `@inneranimalmedia/agentsam-brand` iconography family builder.

- `primetech/v1` — approved PrimeTech five-facet P, eight colorways, three independent shapes (bare P, circle, squircle), with favicon/app/menu/standard/WebP export ladders.
- `inneranimal-cloud/v1` — the two original InnerAnimal cloud system icons (download and code), rebuilt through the same export contract. The original user-supplied ZIP and all original platform exports are retained in the ChatGPT Library at `/PrimeTech/Brand References/Cloud Icon Exports`.

The family manifests are the build inputs. Generated exports are reproducible; the source SVGs and reference assets remain unchanged.
