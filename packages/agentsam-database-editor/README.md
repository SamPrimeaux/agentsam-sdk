# @inneranimalmedia/agentsam-database-editor

Portable Database Editor for AgentSam. Cloudflare D1 and Supabase are **adapters**, not the product.

See [docs/HARVEST_REPORT.md](./docs/HARVEST_REPORT.md) for the full pre-commit harvest (donor map, contracts, installer, Intelligence/WAI policy).

```sh
agentsam app install database-editor
# or
curl -fsSL https://agentsam.inneranimalmedia.com/install | bash -s -- --app-id database-editor
```

`app_id` is stable product identity. No `AGENTSAM_DEFAULT_APP`.
