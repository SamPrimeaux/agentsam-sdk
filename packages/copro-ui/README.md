# @inneranimalmedia/copro-ui

CoPro creator-facing UI primitives.

The UI is mobile-first and supports real editing rather than a read-only companion view: preview, transport/playhead, horizontal timeline, clip selection, direct dragging, trim handles, contextual editing tools, creator tool tray, undo/redo, and responsive desktop composition.

Canonical mutations are delegated to copro-editor. Infrastructure controls are intentionally absent from the creator surface.
