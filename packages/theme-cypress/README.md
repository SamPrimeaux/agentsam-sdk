# @inneranimalmedia/theme-cypress

**Cypress** is an AgentSam prebuild for community / nonprofit.

Warm, grounded, built for belonging.

A welcoming community prebuild for organizations that need events, groups, giving, visits, and mission-driven storytelling without looking like a generic nonprofit template.

Demo identity: **Cypress Commons**. The demo content is fictional and exists to show the layout, interaction, and content system without carrying customer branding forward.

The complete built platform ships in `site/`; installation does not depend on the AgentSam gallery or a sync step.
