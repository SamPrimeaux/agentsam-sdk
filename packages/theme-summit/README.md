# @inneranimalmedia/theme-summit

**Summit** is an AgentSam prebuild for consulting / portfolio.

A quieter kind of authority.

A restrained consulting and portfolio prebuild with editorial services, case studies, multilingual-ready structure, media, and thoughtful spacing that lets expertise do the talking.

Demo identity: **Summit Practice**. The demo content is fictional and exists to show the layout, interaction, and content system without carrying customer branding forward.

The complete built platform ships in `site/`; installation does not depend on the AgentSam gallery or a sync step.
