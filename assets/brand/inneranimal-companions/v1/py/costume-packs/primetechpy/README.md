# PrimeTechPy

PrimeTechPy is a costume and animation add-on for the existing `py` companion, not a new animal identity. It adds ten scientist, data, coding, research, and creative-tooling directions.

## Ten directions

- **Lab Coat Idle** — Scientific exploration
- **Data Diver** — Data inspection and analysis
- **Code Swimmer** — Writing and refactoring code
- **Circuit Scout** — Tracing systems and connections
- **Debug Detective** — Reproducing and resolving defects
- **Research Presenter** — Explaining and presenting findings
- **Sketch Coder** — Wireframes and creative prototypes
- **Success Spark** — Celebrating completed work
- **Thoughtful Coil** — Planning and reflective work
- **Ocean of Syntax** — Immersive code and syntax flow

Each direction has its own visual enhancement and signature motion in `pack.json`. The reference sheet still needs local asset ingestion, slicing into transparent frames, and runtime validation before publication.
