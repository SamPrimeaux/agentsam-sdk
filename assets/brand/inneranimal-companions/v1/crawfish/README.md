# Crawfish companion brief

- **Species:** Louisiana crawfish
- **Habitat:** bayou-gulf
- **Role:** Debugging · bug triage & repair
- **Asset status:** brief-only

The bug catcher. Finds small defects, isolates the cause, and pinches troublesome bugs out of the codebase.

## Character direction

A bright Louisiana crawfish with expressive claws, a compact utility belt, and a small inspection lens; playful but precise.

## Signature action

A quick double-pinch that catches a bug and flicks it into a tiny evidence jar.

This is a catalog brief, not a runtime release. Do not stage as selectable until the transparent animation package, avatars, and manifest assets pass validation.
